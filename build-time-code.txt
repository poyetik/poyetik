# The register of third-party code that runs at build time: every build script and
# procedural macro of a crate either Cargo workspace builds, at its exact version, with what
# it does (reviewed 2026-11-19: none downloads, uses the network or writes outside its
# OUT_DIR). `cargo xtask check` refuses an unreviewed one and a stale line, so that a new
# crate or a new version (a Dependabot update) is refused until reviewed: refused, not kept
# from running, since xtask's own tree builds first, the static steps run before the gate,
# and CI runs the parts that build beside it (whether it runs first: #24 step 30). Format: `<crate>@<version> (<build script|proc macro>) -- <what it does>`.
#
