# The words GLOSSARY.md replaces: one concept, one word. `cargo xtask check` refuses each
# term below in the prose of the repository (Markdown outside code blocks; the comments and
# string literals of Rust and TypeScript; the string values of the JSON files under spec/ and
# conformance/), case-sensitively, as a whole word, never inside a
# name or a code span; a literal of one word alone (a key, a program name) is a name too.
#
#   forbid <term> -> <instead>[ in <path>…] -- <reason>   refused (in those files or directories only)
#   allow <term> in <path> -- <reason>                    allowed in a file or directory (ending with /)
#   allow <term> as "<phrase>" -- <reason>                allowed inside this phrase
#
# Every allowance must still allow something. The gate cannot tell the sense of a word:
# "block" is the engine's word, so only its uses that can only mean a render quantum are
# refused (in the playground, which never sees an engine block, and "tap block").
