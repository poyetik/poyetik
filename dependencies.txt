# Direct dependencies: every third-party crate and npm package a part of the repository
# depends on directly, with the reason it is needed. Parts of the repository that depend on
# each other (path and `workspace:` dependencies) are not listed.
#
# Adding a dependency means adding its line here, with its reason, after its entry in the
# dependency register of the local design notes (see CLAUDE.md, "Technologies and
# dependencies"): as few as possible, mainstream and well maintained.
# Format: `<crate or package directory>: <dependency> (<kind>) -- <reason>`, the kind being
# Cargo's (`normal`, `dev`, `build`) or the package.json field.
# `cargo xtask check` fails on any direct dependency not listed, and on any stale entry.

engine-cli: serde (normal) -- reads the conformance case files into typed values, refusing unknown fields
engine-cli: serde_json (normal) -- parses the case files and writes the reference hashes
engine-core: libm (normal) -- the math functions of the engine's math layer (sine, floor), deterministic and portable, identical on every target where std's are not; boxes reach them only through the layer
engine-core: serde_json (dev) -- reads the shared test matrix, so the unit tests run at every sample rate of conformance/test-matrix.json
engine-fpenv: serde_json (dev) -- reads the conformance cases and their reference hashes, rendered under every forced host mode
engine-hash: serde_json (dev) -- reads the shared known-answer vectors of spec/render-hash-vectors.json
engine-hash: sha2 (normal) -- the SHA-256 of a render, without std, the same on every target
engine-objects: libm (dev) -- the exact references of the tests (sine, exponent, logarithm), computed apart from the math layer of the boxes they check
engine-objects: serde_json (dev) -- reads the shared known-answer vectors of spec/measurement-vectors.json (the error bound of a sine)
engine-patch: serde (normal) -- reads the patch format into typed values, refusing unknown fields
engine-patch: serde_json (normal) -- parses patch documents
engine-testkit: libm (normal) -- deterministic math functions (sine, cosine, logarithm) for the measurements, identical on every target where std's are not
engine-testkit: proptest (normal) -- property tests of the box and plan laws, from a fixed seed
engine-testkit: serde_json (dev) -- reads the shared test matrix, conformance/test-matrix.json
xtask: serde_json (normal) -- reads the coverage, mutation and license reports, the Cargo metadata and the package manifests
