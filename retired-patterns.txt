# Patterns a fix retired: `cargo xtask check` refuses each in the tracked text files of its
# scope (code, tests, documentation, configuration; this list, the gate's tests and the
# released sections of the changelog apart), so that a fix covers every site, not only
# those its finding listed (`crates/xtask/src/retired.rs`). The commit that retires a
# pattern adds it here.
#
#   retire `<pattern>`[ in <path>…] -- <reason>   refused as written, case sensitive, in the
#                                                  files and directories (ending with /)
#                                                  named, or everywhere when none is
#
# A pattern covers the whole tree: an entry narrowed to paths ends its reason with
# `; kept elsewhere: <why>`, why the rest of the tree may keep it. Every path named must
# still hold a tracked source.

retire `is_none() ||` in crates/visual-gpu/ -- an assertion a passing sibling test makes true (a time only from a GPU with a clock, where every test runs on one): vacuous; the case it guards is tested through its own environment, `GpuSquare::open(.., false)` (third deep review of visual block 2, C5-8); kept elsewhere: an `||` of code after a test of absence is legitimate logic outside an assertion (the preflight's)
retire `did not give the image back` -- `GpuError::Lost` covers the encoded bytes too: "the GPU device was lost" (third deep review of visual block 2, C13-1)
retire `did not give its work back` -- `GpuError::Lost` also says a loss while opening and an error caught on a lost device: "the GPU device was lost" (fifth deep review of visual block 2, H14-2)
retire `shown, not checked` -- a GPU the baseline does not hold renders nothing and its time is not checked: "its time is not checked, nothing rendered" (third deep review of visual block 2, C16-1)
retire `only idle` -- load does not move the GPU's time (61 loaded runs within the idle runs' deviations): a bless needs AC power, not an idle machine (third deep review of visual block 2, C16-1)
